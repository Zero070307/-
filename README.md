# 教师学员管理系统

离线、单设备使用的学员、签到与档案管理页面。

## 使用方法

- `index.html`：正式使用页面。
- `teacher-app.html`：与正式页面保持同步的测试页面。
- 双击任一 HTML 文件即可在浏览器中打开。

## 本次更新

- 删除签到记录时可选择仅删除，或删除并加回 1 课时。
- 批量签到增加最终确认页面，确认时使用当前时间记录签到。
- 新增剩余课时不超过 2 节的预警卡片与筛选。
- 学员列表新增最近添加、姓名、剩余课时、班级排序，以及每页 10 人的分页。
- 窄屏设备显示学员卡片，便于手机操作。
- 班级名称会清除首尾空格；新增手机号格式检查与重复学员提醒。

## 验证

运行以下命令可检查核心数据逻辑：

```powershell
node tests/student-management-logic.test.mjs
```

本项目可能包含姓名、电话和页面访问密码等数据。若仓库为公开状态，请勿上传真实学员数据或任何敏感信息。
